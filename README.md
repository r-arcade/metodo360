# Método Vistoria 360 — Landing Page

MVP da landing page do curso Método Vistoria 360, desenvolvido em React e Vite.

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
npm run preview
```

## Configuração pendente

O preço, parcelamento, acesso, garantia, suporte e link de checkout ficam centralizados em `src/config.js`. Antes da publicação, defina `CHECKOUT_URL` com o endereço real da Hotmart e confirme a condição de parcelamento.

Também devem ser substituídos os placeholders de fotografia, provas sociais, links legais, contato e imagem de compartilhamento.
